Разделение пати — Weekday Instance

Подземелье делится на непересекающиеся ветки — по числу участников, примерно поровну по длине. Каждый бегает только по своей ветке (никто не дублирует чужой коридор). Добавь участников — ветки распределятся автоматически, перетаскиванием можно поменять, кто какую бежит.

    Добавь участников похода — каждому будет назначена своя линия патрулирования. Перетащи строку вверх/вниз, чтобы поменять участников линиями.
