Карта Редактор пресетов

Разделение пати — v2 (пресеты)

Маршруты не вычисляются — они берутся готовыми из preset.json по числу участников.

    Выбери число игроков (4–12) — пресет применится сразу, появится ровно N линий. Впиши имена через значок карандаша у каждой строки. Перетащи строку вверх/вниз, чтобы поменять участников линиями.
